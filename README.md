# 🪟 Modal Window

A reusable modal (popup) component built with vanilla JavaScript, HTML and CSS.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

**🔗 Live demo:** [
prasad-modal-window.netlify.app](#)

---

## ✨ Features

- Opens a modal with an overlay behind it
- Smooth scale animation when opening and closing
- Three ways to close it:
  - The **×** button
  - Clicking the overlay
  - Pressing the **Esc** key

---

## 🧠 What I Practised

- Selecting and manipulating DOM elements
- Adding and removing CSS classes to show and hide elements
- Handling click and **keyboard** events (`keydown`)

---

## 🛠️ Tech Stack

- **HTML5** — structure
- **CSS3** — styling and transitions
- **JavaScript (ES6)** — event handling

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/prasad-k-s/Modal-Window.git
cd Modal-Window
```

Then open `index.html` in your browser.
